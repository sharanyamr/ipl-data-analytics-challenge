# IPL Crunch '26 Analysis

## Overview
This project analyzes IPL ball-by-ball datasets to uncover insights related to:
- Toss impact
- Match-winning phases
- Top batters
- Top bowlers
- Hidden IPL trends

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Insights
- Toss advantage exists but is relatively small.
- Death overs have the strongest correlation with winning.
- Virat Kohli leads all batters in total runs.
- Yuzvendra Chahal leads wicket-taking charts.
